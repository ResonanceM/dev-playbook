# Team Ops & Developer Experience (DevEx)

---

## 🎯 The 4 DORA Metrics

| Metric | Goal (Elite Team Target) | How to Improve |
| :--- | :--- | :--- |
| **Deployment Frequency** | Multiple deployments per day | CI/CD automation, trunk-based development |
| **Lead Time for Changes** | $< 1	ext{ hour}$ | Small PRs ($< 250	ext{ lines}$), fast test suites |
| **Change Failure Rate** | $0\% - 15\%$ | Automated integration tests, staging parity |
| **Mean Time to Restore (MTTR)** | $< 1	ext{ hour}$ | Automated rollbacks, feature flags |
