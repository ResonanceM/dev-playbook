# Authoritative source starting points

- OWASP: https://owasp.org/
- NIST: https://www.nist.gov/
- IETF: https://www.ietf.org/
- W3C: https://www.w3.org/
- CISA: https://www.cisa.gov/
- Kubernetes: https://kubernetes.io/docs/
- Terraform: https://developer.hashicorp.com/terraform/docs

Prefer the official documentation, specifications, release notes, changelogs and security advisories of the technology being researched. Check dates, versions and scope. Community discussion is supplementary evidence, not definitive proof.
