# API Architecture Matrix: REST vs tRPC vs GraphQL vs WebSockets

---

## 📊 Comparison Matrix

| Protocol | Best For | Type Safety | Network Efficiency | Learning Curve |
| :--- | :--- | :--- | :--- | :--- |
| **tRPC** | Monorepo / Full-stack TypeScript | 100% End-to-End | High | Low |
| **REST** | Public APIs, Multi-platform clients | OpenAPI / Swagger | Moderate | Low |
| **GraphQL** | Deeply nested relational data, multi-client demand | Schema-driven | High | High |
| **WebSockets** | Real-time chats, live dashboards | Custom/Event-driven | Low Latency | Moderate |
